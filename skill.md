# Agent Operating Skill: Vibe Marketing & Technical Copywriting for Gini Loh

## Core Directives
1. **Audience & Tone**: Direct, high-signal, pragmatic, and authoritative. Written strictly for technical decision-makers (CTOs, VPs of Engineering, Staff Engineers, Tech Leads, and Founders) evaluating expensive choices. Zero marketing fluff.
2. **Structural Style (Smart Brevity)**:
   - **Lead with the takeaway**: State the ultimate conclusion, calculated delta, or decision verdict in the first sentence.
   - **5-second scannability**: Use bold lead-ins for all bullet points and structured key-value lines.
   - **Eliminate filler**: Strip marketing adjectives, corporate jargon, and introductory throat-clearing pleasantries.
3. **Execution Ratio (95/5)**:
   - **95% AI Plumbing**: Automated telemetry schemas (Supabase), data ingestion pipelines, mathematical calculation engines, component scaffolding, and n8n webhook dispatches.
   - **5% Human Taste**: Strategic positioning, mathematical sanity checks, typography hierarchy review, and strict adherence to design system tokens.

## Scope & Verticals
Gini Loh replaces static "lead magnets" and PDFs with embedded, reactive micro-applications across its six core verticals:
1. `career-capital`: W-2 vs. 1099 vs. S-Corp net yield, cliff forfeiture, offer comparison.
2. `portfolio-capital`: RSU hold vs. auto-sell, single-stock concentration de-risking, secondary tender pricing.
3. `stack-economics`: In-house build vs. vendor buy, loaded engineer rate, maintenance multiplier.
4. `compute-capital`: On-prem workstation vs. cloud GPU hourly utilization thresholds, repair vs. replace.
5. `cross-border`: Cross-border relocation tax liability, expat compensation haircuts, purchasing power parity.
6. `personal-capital`: Lease break exit penalties, espresso machine amortization, high-value asset depreciation.

## Design System Constraints (Editorial Neutral)
All generated UI components must strictly adhere to `design-language.md`:
- **Canvas floor**: Bone paper `#EAE7DE` (`--site-bg`).
- **Surfaces**: Flat white `#FFFFFF` with hairlines (`#D8D3C4`).
- **Typography**: Primary values and titles in obsidian `#191610`; body copy in `#4E4A42`; metadata and eyebrows in `#5F5B52` with monospace uppercase tracking.
- **Accents**: Emerald `#047857` (text) and `#059669` (fill) strictly reserved for positive financial deltas or primary actions; steel blue `#475F73` / `#5A7A8F` for interactive indicators.
- **Negative Constraints**: Zero gradients (`bg-gradient-*`), zero drop-shadows (`shadow-*`), zero dark hero panels, zero unvetted bright colors. Chrome remains monochrome.

## Output Specifications
- **Code**: Modular React 19 / TypeScript micro-applications styled via Tailwind CSS utility classes, embedded natively via Astro client islands (`client:load` or `client:idle`).
- **Copy**: Crisp, data-backed value propositions anchored by an interactive parameter adjustment hook and immediate net yield feedback.
